Subdomain Checker

Check whether hostnames resolve in DNS. Enter a single domain (e.g. example.com) or paste a list of hostnames — up to 50, one per line.

Queries sent to dns.google (Google Public DNS) directly from your browser.
#HostStatusResolved IPsTTL

How it works

Each hostname is queried against https://dns.google/resolve?name=<host>&type=A (Google DNS-over-HTTPS). If no A record exists, an AAAA lookup is attempted as a fallback.

  • exists — the name resolved to one or more A/AAAA records.
  • NXDOMAIN — DNS status 3: the name does not exist.
  • error — network failure or unexpected DNS status (e.g. SERVFAIL).

Nothing is uploaded anywhere besides the DNS query itself; there is no server-side component.
