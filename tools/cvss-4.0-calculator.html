What changed in CVSS 4.0

The current version is the next generation of the Common Vulnerability Scoring System, published by FIRST. CVSS v4.0 adds an Attack Requirements (AT) Base metric, introduces Passive and Active User Interaction values, retires Scope in favor of explicit impact metrics for the vulnerable system (VC, VI, VA) and the subsequent system (SC, SI, SA), renames the Temporal group to Threat, and adds a Supplemental Metric Group.

Where v3.1 gave you one number, v4.0 defines named score combinations. The specification identifies CVSS-B (Base), CVSS-BT (Base plus Threat), CVSS-BE (Base plus Environmental), and CVSS-BTE (Base plus Threat plus Environmental). Your vector above is the Base group, which is what most vendors and advisories publish.

If you use the score to decide what to patch first, do not stop at CVSS. FIRST's EPSS project publishes a 0-1 exploitation probability with ranking percentiles every day for every CVE, freely available through CSV, an API, and a GitHub repository, and its guidance covers combining EPSS with CVSS and CISA KEV for prioritization decisions. We use that combination daily when triaging our own findings.

How we know the tool is honest

Methodology. This page is deterministic client-side code implementing the published FIRST CVSS v4.0 specification. Every character in the vector string comes from the metric you clicked, assembled in your browser, with no network request and no stored input. The metric definitions come straight from the FIRST v4.0 specification document. The numeric scoring path is a client-side implementation of FIRST's published macrovector lookup and distance-interpolation algorithm. We verified it by running every one of the 20,969 Base-metric test vectors in FIRST's official cvss-resources reference dataset (vectorFiles/base-threat-scores, fetched from FIRST's GitHub repository on 2026-10-01) through this engine and comparing the scores: 20,969 of 20,969 matched FIRST's published values exactly, with zero mismatches. The v3.1 comparison engine was verified the same way against FIRST's official cvsscalc31.js reference implementation on all 2,592 pure-Base metric combinations, again with zero mismatches. Common questions

Is this calculator free?

Yes, and it runs locally. FIRST also publishes a free official calculator for the version-controlled numeric score.

Why does my vector have an AT metric?

Attack Requirements is new in v4.0. It captures conditions beyond the attacker's control, like race windows or specific configurations. P means those conditions are present.

Does the tool send my data anywhere?

No. All tools run in your browser and produce estimates or simulated output, not authoritative security assessments. Your metric selections never leave the page.
